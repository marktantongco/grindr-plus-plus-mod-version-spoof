The one rule

Edit config only with both apps force-stopped. The manager rewrites grindrplus.json from memory while running and will silently undo your edit.

adb shell am force-stop com.grindrplus
adb shell am force-stop <clonePkg>
# edit, push
adb shell monkey -p <clonePkg> -c android.intent.category.LAUNCHER 1

Signing

mtantongco.keystore — alias mtantongco, pass mtantongco. Different from upstream release and debug signatures: uninstall before switching. Losing the key forces the uninstall dance on every future build.
